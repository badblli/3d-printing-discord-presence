# d1-06-ui — Kurulum sihirbazı, durum ve ayarlar ekranı

- Summary: Kullanıcının yazıcısını birkaç adımda eklediği, Discord kartının canlı önizlemesini gördüğü ve ayarları değiştirdiği arayüz.
- Engine: codex
- Model: standard
- Skill: frontend-design
- Phase: D1
- Branch: `codex/d1-06-ui` (base: `main`)
- Depends on: d1-05-runtime
- Role: implementer

## Goal

Discord Developer Portal'ı hiç bilmeyen biri uygulamayı açıp iki dakikada baskısını Discord'da gösterebilsin.
Use your frontend-design skill.

## Scope

- In: `src/**` (Svelte bileşenleri, stiller, i18n), `src/lib/api.ts`'yi yalnızca kullan.
- Out: `src-tauri/**`.

## Tasks

1. İlk açılış sihirbazı: (a) eski ayarlar varsa "Önceki kurulumu içe aktar"; (b) yazıcı türü seç (Bambu Lab etkin;
   Klipper, OctoPrint, Prusa "yakında" rozetiyle devre dışı); (c) Bambu alanları: IP, seri numarası, LAN erişim kodu,
   model — her alanın yanında "Nerede bulurum?" açıklaması (README'deki tablo); (d) bağlantı testi sonucu; (e) Discord'da
   "Etkinlik Gizliliği → etkinlik paylaşımı" hatırlatması.
2. Ana ekran: yazıcı kartları (bağlantı durumu, ilerleme çubuğu, kalan süre, sıcaklıklar) + Discord kartı önizlemesi
   (`get_snapshot` içindeki seçilen etkinlikten; Discord'un profil kartına benzer).
3. Ayarlar: dosya adını göster, Discord'u aç/kapat, OS açılışında başlat, dil (TR/EN), yazıcı düzenle/sil,
   gelişmiş → kendi Application ID'n (isteğe bağlı).
4. Hata kodlarını (bağlantı/doğrulama) TR/EN anlaşılır metne ve çözüm önerisine çevir (ör. `AuthRejected` → erişim kodu,
   LAN Only/Developer Mode yönlendirmesi).
5. Görsel kimlik: mevcut koyu tema renkleri (`app.py` paleti: #0d1117 zemin, #52dda0 vurgu) ve piksel maskot
   (`assets/app-icon-maker-pixel-v2.png`). Klavye ile kullanılabilir, 760×640 pencerede kaydırmasız ana ekran.
6. Birim testleri (vitest): hata kodu → metin eşlemesi, form doğrulama, i18n anahtarlarının iki dilde eksiksiz olması.

## Acceptance criteria

- [ ] `npm run lint` ve `npm test` temiz.
- [ ] Erişim kodu alanı parola tipinde; kaydedildikten sonra geri gösterilmez (yalnızca "kayıtlı" bilgisi).
- [ ] Tüm metinler i18n dosyalarından; iki dilde eksik anahtar yok (test).
- [ ] Lider `npm run tauri dev` ile sihirbazı baştan sona dener.
